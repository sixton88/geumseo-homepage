- assets/geumseo-symbol-mobile.png : 로고 심볼 이미지

v5 핵심 수정:
- 휴대폰 화면 기준으로 처음부터 다시 제작
- 모바일에서 1열 카드 구조
- PC에서는 자동으로 넓은 레이아웃 적용
- 하단 고정 전화/이메일 버튼 추가
- 가로 스크롤 방지
- 큰 로고 이미지 축소
- 로고는 HTML 내부에도 직접 삽입되어 미리보기에서 깨질 가능성 최소화

- 모바일과 PC 모두에서 작은 로고가 선명하게 보이도록 CSS 보강


v7 수정사항
- 홈페이지 사진 없이 신뢰감을 줄 수 있도록 구조 재작성

- '사진 견적 안내' 섹션 추가
- FAQ 섹션 추가
- 하단 고정 버튼을 문자 사진 문의 중심으로 변경
- 모바일 우선 반응형 구조 유지


v8 수정사항
- 사진 견적 안내 섹션의 내부 설명성 문구 삭제
